实现面向安全日志外发的脱敏器，只处理UTF-8文本及JSON Lines，目标是阻止秘密泄漏并保留可核验结构。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 秘密来自外部传入的有限字典，另外JSON路径password、token、secret指定为敏感；匹配需要覆盖原文、JSON转义及标准base64三种表示，按最长匹配优先、同长按字节序确定处理重叠，不做无限次递归解码。
2. 输入分块边界可落在UTF-8字符、转义和秘密中间；流式结果必须等于一次性参考实现。用带独立盐的HMAC标识替代秘密，同一批次同秘密一致、跨批次不同；不得在异常、调试日志或映射文件中存明文秘密。
3. 每条记录先完整验证再发布，JSON行最多1MiB，超限或语法错误整行隔离且隔离区仅存原文哈希与错误位置；保持非敏感JSON值语义与记录顺序，输出原始字节区间到替换标识的证据索引。

必须覆盖的验收场景：秘密重叠、跨块Unicode、JSON转义后的秘密、base64边界、截断行和超限行；穷举短输入的全部切块位置，并扫描全部输出文件确认无原始秘密。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
